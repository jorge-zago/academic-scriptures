# Contributing

Academic Scriptures welcomes careful technical and scholarly contributions.

Before proposing textual content:

1. Add a complete license record under `content/registry.json`.
2. Provide a stable source URL and identify the copyright holder.
3. Document redistribution, modification, attribution, offline-use, and
   repository permissions.
4. Do not submit content copied from protected websites or undocumented APIs.

All substantive historical or theological claims should identify their source
and distinguish direct textual evidence from interpretation.

Run `npm run check` and `npm run build` before opening a pull request.
