# Content licensing policy

The MIT license in this repository applies only to software and project
documentation unless a file explicitly says otherwise.

A corpus may be added only after its registry entry documents:

- canonical source and copyright holder;
- exact license or written permission;
- attribution requirements;
- permission to redistribute and modify;
- permission for offline download;
- repository and API restrictions;
- territory and commercial-use restrictions;
- checksum and acquisition date.

Public-domain status must be verified for the relevant jurisdictions. Mere
online availability, API access, nonprofit use, or delivery one verse at a
time does not establish redistribution permission.
